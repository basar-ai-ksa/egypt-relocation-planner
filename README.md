# New Cairo Relocation & Budget Planner

An interactive, visual financial application and decision dashboard for a family of four (parents + children aged 8 and 10) relocating to New Cairo, Egypt for 6 to 12 months with a monthly target envelope of **15,000 to 20,000 SAR**.

---

## Quick Start

### Option 1: Direct Browser Access
Simply open [index.html](file:///Users/abclaw/.gemini/antigravity/scratch/egypt-relocation-planner/index.html) in any modern browser (Chrome, Safari, Edge, Firefox).

### Option 2: Run Local Python Server
Run the included local server script:
```bash
python3 /Users/abclaw/.gemini/antigravity/scratch/egypt-relocation-planner/serve.py
```
Then navigate to: **[http://localhost:8080](http://localhost:8080)**

## Features

- **Dynamic Budget Slider:** Test budgets from 12,000 SAR to 25,000 SAR with real-time surplus/overage indicator.
- **Multi-Currency Toggle:** Instant conversions across **SAR, EGP, GBP (£), EUR (€), and USD ($)**.
- **Schooling Stream Toggle:**
  - *Lycée Français du Caire (LFC New Cairo)* - French AEFE stream (~€4,528/yr per child, French consular grant eligible).
  - *Malvern College Egypt* - British EYFS/KS1-2 (~255,000 EGP/yr per child).
  - *Modern English School (MES Cairo)* - Dual British/American (~235,000 EGP/yr per child).
- **Housing Customizer:** 3-Bed compound apartment (Mountain View / Palm Hills) vs. Luxury Mivida Penthouse vs. Townhouse with garden.
- **Mobility Customizer:** Dedicated long-term rental car + fuel vs. Uber/Careem + school bus passes.
- **Domestic Help Customizer:** Part-time cleaner (3 days/wk) vs. Full-time live-out maid/cook (5 days/wk) vs. none.
- **Shariah Healthcare (Takaful):** Top-tier local network (Air Force Specialized Hospital, Al Salam) vs. regional expat policy.
- **Visual Explorer:** Direct photographs, descriptions, and verified links for New Cairo compounds, schools, hospitals, and fitness centers.
- **One-Time Setup Calculator:** Upfront flight estimates, 2-month refundable landlord deposits, real estate broker fees, visas, and school admission charges for 6 vs. 12 month horizons.
